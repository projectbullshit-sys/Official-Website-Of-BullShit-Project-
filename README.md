# BULLSHIT PROJECT — DBDM Community Website

A responsive single-page community website using the dark red/black Entity-inspired visual theme.

## Preview
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Keep `index.html`, `style.css`, and `script.js` together in the same folder.

## Configure community links
Open `script.js` and replace the values in `LINKS`:
- `discord`: main Discord invite
- `appeals`: appeals server invite
- `kofi`: Ko-fi page
- `telegram`: daily rewards Telegram bot

The Discord link currently points to the generic Discord homepage until the real invite is supplied. Other unavailable links are deliberately placeholders.

## Downloads
The iOS and Android MediaFire links were supplied by the site owner and included as third-party, unverified links. The website clearly warns visitors that their safety, authenticity, compatibility, and legality have not been verified.

## Character directory
The interactive character archive includes a historical mobile roster reference with 30 Survivors and 27 Killers. Use the tabs to switch sides, search names/perks/powers, and select a portrait card to open its detailed profile. Profiles include background summaries, difficulty, unique perks, playstyle notes, Killer powers, and franchise/origin labels.

The roster is based on the published Pocket Gamer DBD Mobile character list and should be treated as a historical reference: availability differed by region and game version. Portraits load remotely from Dead by Daylight wiki image files when matching files are available; an initials fallback keeps the cards usable if an image cannot load.
